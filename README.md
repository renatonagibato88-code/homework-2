# Домашнее задание к работе 2

## Условие задачи

Фруктовый магазин продает яблоки поштучно по 1 руб., груши — по 2 руб., апельсины — по 3 руб. Известно, что в понедельник продано x яблок, y груш и z апельсинов, во вторник — также x яблок, y груш и z апельсинов. Напишите программу, которая вычисляет, какую сумму магазин продал фруктов в каждый из этих дней.
Анализ задачи

Юра тратит на сладости $X$ рублей, и это $\frac{1}{4}$ от всех его карманных денег за неделю. Следовательно, всего в неделю он получает $W = X \cdot 4$.
После покупки сладостей у него остается $R = W - X$ рублей.
Из остатка он сберегает одну треть, то есть в неделю он копит $S = \frac{R}{3}$.
В году 52 недели. Значит, за год он накопит $Total = S \cdot 52$.

Алгоритм решения

Начало алгоритма.
Задать значение переменной $X$ (сумма, которую Юра тратит на сладости).
Вычислить еженедельную сумму: $W = X \cdot 4$.
Вычислить остаток после покупки сладостей: $R = W - X$.
Вычислить еженедельные сбережения: $S = R / 3$.
Вычислить годовые сбережения (учитывая 52 недели в году): $Total = S \cdot 52$.
Вывести результат $Total$.
Конец алгоритма.

### Блок-схема


## 2. Реализация программы

#include <stdio.h>

int main() {
    // Задаем определенное значение для трат на сладости (X)
    double X = 500.0;

    // Вычисления согласно алгоритму
    double W = X * 4.0;         // Общая сумма в неделю
    double R = W - X;           // Остаток после покупки сладостей
    double S = R / 3.0;         // Сбережения за одну неделю
    double Total = S * 52.0;    // Накопленная сумма за год (52 недели)

    // Вывод результатов на экран
    printf("Траты на сладости в неделю: %.2f руб.\n", X);
    printf("Сумма, накопленная Юрой за год: %.2f руб.\n", Total);

    return 0;
}
